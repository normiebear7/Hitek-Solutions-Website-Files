Industrial Router Controls Redesign

This project delivered a complete controls redesign for an industrial router after repeated legacy servo-drive failures created reliability issues and operating friction.

Dimensional Metrology System

Automotive Camshaft Lobe Dimensional Measurement

This project measured automobile engine camshaft lobes at numerous points around each lobe and continuously evaluated dimensional conformance inside a live spreadsheet workflow. If a lobe was out of spec, the system immediately flagged it and prevented the part from being accepted.

Task Undertaken

  • Collect precise measurement data around each camshaft lobe at multiple defined probe positions.
  • Record each measurement set into a continuously updating spreadsheet for on-the-spot dimensional evaluation.
  • Identify nonconforming lobe geometry as soon as a reading exceeded allowed tolerance bands.

Provided Solution

  • Built an HMI workflow that guided operators through each measurement point and displayed live values.
  • Automated Excel data capture and formula-based conformance checks for every inspected lobe.
  • Added immediate out-of-spec alerts to support fast operator action and prevent bad-part acceptance.
Aerospace Reliability Validation System

Commercial Aircraft Oxygen Mask Switch Evaluation

Before this upgrade, the customer tested one switch at a time with a manual process that consumed significant operator time and introduced data-entry errors. In collaboration with their engineering team, we developed a new test fixture and automation workflow to validate switch behavior across descending and ascending cycles with reliable spreadsheet-based reporting and clear fail tracking.

Task Undertaken

  • Replace one-at-a-time manual testing with a multi-switch validation method for commercial airline oxygen-mask release switches.
  • Collaborate with customer engineering to define a fixture assembly that could test up to 25 switches in parallel.
  • Monitor switch closure state through descending and ascending altitude simulation actions and identify any switch that failed test criteria.

Provided Solution

  • Designed, built, tested, and commissioned a 25-switch fixture integrated with PLC controls, altitude simulation, and PC-based HMI workflow.
  • Automated event capture and spreadsheet logging to reduce manual data handling errors and improve traceability.
  • Delivered immediate pass/fail reporting for fast corrective action; customer feedback described this solution as revolutionizing that part of their business.
