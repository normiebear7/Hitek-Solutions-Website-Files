How Machine Learning Learns

AI is only as good as the labels in its data. This guide explains the three ways machine learning learns — through the same machine scenario as the companion paper — and which one to use for which job.

Supervised learning — learning from answered examples

Show the system many cycles where the answer is already known (pass or fail) and it learns to predict the answer for new cycles it has never seen.

Unsupervised learning — finding patterns nobody labelled

With no answers at all, it learns what “normal” looks like, flags unusual cycles, finds new fault types, and spots slow drift over weeks.

Reinforcement learning — learning by trial, error and reward

The system tries small adjustments, scores the result, and learns which ones keep the process centred — trained in simulation first, with the PLC’s safety limits always in charge.

Why labels matter

A label is simply the answer attached to a piece of recorded history. Clean labels matter more than a clever model.

The three methods, side by side

In practice a real plant system uses more than one: unsupervised watches for drift, supervised predicts part quality, reinforcement tunes the process to stay centred.
